# El Pollo Loco

A browser-based 2D platform game built with vanilla JavaScript, HTML, and CSS. Guide Pepe through a desert level, collect coins and salsa bottles, avoid chickens, and face the end boss.

## Features

- Keyboard and touch controls
- Running, jumping, and bottle throwing
- Chicken enemies and an end boss
- Coins, bottle pickups, and status bars
- Win and game-over screens
- Music and sound controls with saved audio preferences
- Responsive layout with a landscape prompt for phones

## Getting Started

No package installation or build step is required. Serve the project folder with a local web server.
